ポーズ集（SOMA の出力から育つ）
操作 視線：正面
黄色の球
手・腰・頭・足。ドラッグで引っ張る。見えない物理が体の反応を計画し（薄い人形）、SOMA がそこへ動く。強く引くとよろけて踏み出し、引き続けると歩き、走る
足をゆっくり上げる
足が指についてくる。片足で立ってポーズをつけられる。離すとその下に足を置く
足を素早く上げる
膝より上でキック（高ければハイキック。速く引くほど速く蹴る）。一発蹴って足を下ろす
腰を素早く上へはじく
小さくジャンプ（はじいた向きへ少し進む）
低く引く／頭を下げる・上げる
腰や手を低く引くとかがんで歩き、頭を下げると背を丸め、上げると胸を張る。強く引くほど速い。ゆっくり横へ引くと横歩き
やりすぎると
強く引きすぎると嫌がり（足を引きずる・顔をそむける）、まだ引きずると転んで起き上がる。あっちこっちへ振ると困って頭をかく
少しだけ引く／止めて待つ
少し引くと一歩踏み込み、もっと引くと歩く。指を止めて落ち着いた姿勢は「作ったポーズ」に残り、次に同じように引いたときの姿勢に混ざる
Shift ＋ドラッグ
床と平行に引く（奥・手前へ）
水色の球
見る方向・正面。ドラッグすると、その方向を体に対して固定する
ピンクの球
見る方向・体に対して固定。歩いても向きを変えても、体から見て同じ方向を見続ける（後ろなら肩越しに）。ダブルクリックで正面に戻す
空いた所をドラッグ
視点を回す（ホイールで寄る・離れる）。カメラは体についてくる
画面の端で止める
引っ張ったままマウスを端に置くと、どこまでも歩き続ける

SOMA Pull

人形の手・腰・頭・足をつかんで引っ張ってください。ひもで引かれたように体が向きを変え、歩いたり走ったりしてついてきます。動きはすべて NVIDIA の MotionBricks（SOMA）がブラウザの中でその場で生成します。目標にする歩きのポーズは、モデル自身が出した動きから集めて育てます。

モデル

初回は NVIDIA の GitHub からモデルをダウンロードしてブラウザに保存します（格闘ゲームと共通）。利用条件は NVIDIA Open Model Agreement。

WebGPU に対応したデスクトップの Chrome / Edge が必要です。
