SOMA Pose Lab

MotionBricks（SOMA）が、ストックから選んで変異させた姿勢へ向かう動きを次々に生成します。生成された動きの途中の姿勢を取り出し、さらに変異させてストックに加えるので、姿勢はだんだん人間離れしていきます。手足を引っ張ると、引っ張られた人のように体がついてきます。

モデル

初回は NVIDIA の GitHub からモデルをダウンロードしてブラウザに保存します（格闘ゲームと共通）。利用条件は NVIDIA Open Model Agreement。

WebGPU に対応したデスクトップの Chrome / Edge が必要です。
