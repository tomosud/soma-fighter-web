SOMA Fighter Web

動きはすべて、NVIDIA の MotionBricks（SOMA モデル）があなたのブラウザの中でその場で生成します。用意したアニメーションは再生しません。構え・打撃・のけぞり・ダウンの「キーポーズ」（Mixamo のモーションから取ったもの）だけを相手の位置に合わせて置き、そこまでの動きを毎回生成します。

モデル

初回は NVIDIA の配布元（GitHub）からモデルをダウンロードし、ブラウザに保存します。2 回目からは保存したものを使います。モデルの利用条件は NVIDIA Open Model Agreement です。

WebGPU に対応したデスクトップの Chrome / Edge と、数 GB の空きメモリが必要です。

SOMA Pull：人形の手や腰を引っ張ると、歩いたり走ったりしてついてくる。
